# টেম্প মেইল — Netlify-তে ফ্রিতে চালু করার নিয়ম

এই ফোল্ডারে তোমার টেম্প মেইল সাইটের পুরো প্রজেক্ট আছে। এটা Netlify-তে ফ্রিতে চালানো যায় — **কোনো টাকা লাগবে না, ফোন ভেরিফিকেশনও লাগে না**। শুধু একটা GitHub অ্যাকাউন্ট আর একটা Netlify অ্যাকাউন্ট লাগবে, দুটোই ফ্রি।

> আগে Vercel-এ চেষ্টা করা হয়েছিল, কিন্তু Vercel ফোন ভেরিফিকেশন চায় আর লেবানন নাম্বারটা ১২ ঘণ্টার জন্য ব্লক করে দিয়েছিল। তাই এখন Netlify-ই মূল রাস্তা। Vercel-এর ফাইলগুলো (`api/`, `vercel.json`) রিপোতে থেকেই গেছে — পরে চাইলে Vercel-এও চালানো যাবে।

## ধাপ ১ — GitHub-এ রিপো বানাও

১. ফোনের ব্রাউজারে যাও: **github.com** — অ্যাকাউন্ট না থাকলে ফ্রিতে একটা খুলে নাও (ইমেইল আর পাসওয়ার্ড দিলেই হয়)।
২. ওপরে **+** চিহ্ন চাপো → **New repository**।
৩. নাম দাও: `temp-mail` → নিচে **Create repository** চাপো।
৪. এবার **"uploading an existing file"** লেখাটায় চাপো (অথবা Add file → Upload files)।
৫. এই ফোল্ডারের **সব ফাইল আর ফোল্ডার** (public, netlify, netlify.toml, api, vercel.json, package.json, README.md) আপলোড করো → **Commit changes** চাপো।

## ধাপ ২ — Netlify-তে ফ্রি অ্যাকাউন্ট খোলো

১. যাও: **netlify.com** → **Sign Up** চাপো।
২. **Continue with GitHub** চাপো → GitHub-এ লগইন করে অনুমতি দাও। কোনো কার্ড বা টাকা লাগে না, ফোন নাম্বারও চায় না।

## ধাপ ৩ — সাইট Deploy করো

১. Netlify-এর ড্যাশবোর্ডে **Add new site → Import an existing project** চাপো।
২. **GitHub** বেছে নাও → তোমার `temp-mail` রিপোটা খুঁজে পাশে **Import** চাপো।
৩. কিছু বদলাতে হবে না (netlify.toml-এ সব লেখা আছে) — শুধু **Deploy site** চাপো।
৪. ১–২ মিনিট অপেক্ষা করো। হয়ে গেলে একটা ঠিকানা পাবে, যেমন: `temp-mail-xxxx.netlify.app` — এটাই তোমার সাইট। ব্রাউজারে খুলে দেখো, ঠিকানা তৈরি হবে আর মেইল আসবে।

## ধাপ ৪ — এড বসানো (আয়ের জন্য)

১. **Monetag** (monetag.com) বা **Adsterra** (adsterra.com) — যেকোনো একটায় ফ্রি অ্যাকাউন্ট খোলো। ওরা নতুন সাইট ১০ মিনিট থেকে ১ দিনের মধ্যে অনুমোদন দেয়, ভিজিটরের কোনো শর্ত নেই।
২. অ্যাকাউন্টে তোমার সাইটের ঠিকানা (`...netlify.app`) দিয়ে ওয়েবসাইট যোগ করো। ওরা একটা **এড কোড** দেবে (ছোট একটা কোড)।
৩. GitHub-এ তোমার রিপোতে যাও → `public/index.html` ফাইলটা খোলো → **AD SLOT 1** আর **AD SLOT 2** লেখা জায়গা দুটো খুঁজে বের করো → কোডটা সেখানে বসিয়ে **Commit** করো।
৪. Netlify নিজে থেকেই সাইটটা আবার বানিয়ে নেবে (redeploy)। কয়েক মিনিট পর তোমার সাইটে আসল এড দেখা যাবে।

## আয় কীভাবে হবে?

- ভিজিটর তোমার সাইটে এলে এড দেখবে। ভিউ আর ক্লিক থেকে টাকা Monetag/Adsterra অ্যাকাউন্টে জমতে থাকবে।
- **৫ ডলার** হলেই টাকা তোলা যায়।
- আয় পুরোপুরি ভিজিটরের ওপর নির্ভর করে — ভিজিটর না থাকলে এড থাকলেও আয় হবে না। তাই সাইটের লিংক শেয়ার করো, মানুষ এলে আয় শুরু হবে।

## AdSense পরে (এখন দরকার নেই)

Google AdSense-এর জন্য নিজের কেনা ডোমেইন লাগে (টাকা লাগে) আর কঠিন যাচাই হয়। এখন দরকার নেই। পরে ভিজিটর বাড়লে নিজের ডোমেইন কিনে AdSense-এর জন্য আবেদন করা যাবে — তখন Monetag/Adsterra-র জায়গায় AdSense-এর কোড বসালেই হবে।

## সতর্কতা

- টেম্প মেইল দিয়ে ব্যাংক, টাকা-পয়সা বা পাসওয়ার্ড রিকভারির মতো গুরুত্বপূর্ণ অ্যাকাউন্ট খুলো না।
- কিছু ওয়েবসাইট টেম্প ডোমেইন ব্লক করে — তখন নতুন ঠিকানা বানিয়ে অন্য ডোমেইন দিয়ে চেষ্টা করো।

## ফাইলগুলো কী কী

- `public/index.html` — সাইটের পেজ (ইংরেজি)
- `public/styles.css` — রঙিন ডিজাইন
- `public/app.js` — ঠিকানা বানানো, ইনবক্স, কোড কপি — সব কাজ
- `netlify/functions/*.js` — Netlify-এর সার্ভার ফাংশন; mail.tm-এর সঙ্গে কথা বলে (ব্রাউজার সরাসরি mail.tm-এ যেতে পারে না, তাই এই প্রক্সি লাগে)
- `netlify.toml` — Netlify-এর সেটিংস (public ফোল্ডার, ফাংশন, /api/* রিরাইট)
- `api/*.js`, `vercel.json`, `package.json` — Vercel-এর জন্য রাখা আছে (পরে Vercel-এ চালাতে চাইলে কাজে লাগবে)
